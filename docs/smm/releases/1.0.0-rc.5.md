# smm 1.0.0-rc.5 — first public release

Branch `smm`: upstream Mattermost `8a378be804` plus the smm changes, squashed.

## What it is
- Mattermost server and stock web app with encryption at rest: AES-256-GCM, one derived key per channel and DM,
  AEAD bound to team, channel, column and row; HMAC blind-index search; encrypted file blobs.
- Root key only in OpenBAO: sealed raft storage, Shamir 3-of-5, read-only AppRole, audit log, fail-closed start.
- No calls to Mattermost, Inc.; push off by default; hashed session tokens; locked release profile with a TLS edge
  and IP allow-list.
- Source-available `server/enterprise` code removed.

## Changed since rc.4
- Renamed to SMM; attribution in `NOTICE.md`; architecture and step-by-step guides.
- Bundled identity provider removed: SSO is off unless you point it at your own OpenID Connect IdP.
- Repository trimmed to server + KMS + deployment. No client builds, push proxy or experimental client.

## Known limits
- Runs as the free (Team) edition: user cap, no OpenID button in the stock login page, no MFA enforcement or guests.
- Not end-to-end encryption; see `docs/ARCHITECTURE.md` §6.

## Verified (2026-10-25)
`prove-encryption.mjs`: all checks passed. AEAD binding tests (`TestPostCipher`, `TestSealPosts`): pass.

## Install
`cd deploy && cp .env.example .env` (fill in), then `docker compose up -d`: builds the image, sets up OpenBAO
(init, unseal, AppRole) and starts. No users are created. See `docs/smm/STEP-BY-STEP.md`.
